# AceBot Frontend

This project is built with [Vite](https://vitejs.dev/) and React + TypeScript.

## Available Scripts

In the project directory, you can run:

### `npm start`

Runs the app in development mode using the Vite dev server.\
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

The page reloads instantly on edits via Vite's Hot Module Replacement (HMR).

### `npm run build`

Type-checks the project (`tsc --noEmit`) and builds the app for production to the `dist` folder.\
The build is minified and the filenames include content hashes.

### `npm run preview`

Serves the production build from `dist` locally, to sanity-check it before deploying.
